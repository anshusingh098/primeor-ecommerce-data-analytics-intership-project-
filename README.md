# Primeor Solutions - E-Commerce Data Analytics Internship Final Submission

## Project Overview
This repository contains the complete deliverables for the **Primeor Solutions Data Analytics Internship Project**. The project encompasses:
- **Level 1: Data Understanding & Cleaning (Excel & Python)**
- **Level 2: Data Analysis & SQL Mining (SQLite / MySQL / PostgreSQL)**
- **Level 3: Power BI Dashboard & Visualizations (Multi-Page Executive Report)**
- **Final Business Insights Report (.pdf)**

---

## Directory & File Structure

```
Primeor_Solutions_Internship_Final_Submission/
├── Level_1_Excel_Data_Cleaning_and_Analysis/
│   ├── Cleaned_Dataset.csv                  <- Fully cleaned and standardized dataset (CSV)
│   ├── Cleaned_Dataset.xlsx                 <- Cleaned dataset formatted in Excel

│   ├── primeor_ecommerce.db                 <- Ingested SQLite database containing table 'sales_data'
│   └── sql_insights_summary.md              <- Written answers and executive insights for SQL queries

│   ├── PowerBI_Measures_and_Guide.md        <- Data model architecture, DAX formulas & visual setup guide

│   ├── page1_executive_overview.png         <- High-resolution render of Page 1: Executive Overview
│   ├── page2_sales_analysis.png             <- High-resolution render of Page 2: Sales Analysis
│   └── page3_product_customer_insights.png  <- High-resolution render of Page 3: Product & Customer Intelligence

└── README.md                                <- Documentation and submission guide
```

## How to Review and Run Deliverables
1. **Interactive Power BI Dashboard**:
   - Double-click `Level_3_PowerBI_Dashboard/interactive_dashboard.html` to open the interactive executive dashboard in Chrome/Edge/Firefox.
2. **SQL Database**:
   - Open `Level_2_SQL_Analysis/primeor_ecommerce.db` in VS Code (using *SQLite Viewer* extension) or DBeaver / DB Browser for SQLite.
   - Run queries from `Level_2_SQL_Analysis/sql_queries.sql`.
3. **Excel Analysis Workbook**:
   - Open `Level_1_Excel_Data_Cleaning_and_Analysis/Excel_Analysis_Workbook.xlsx` in Microsoft Excel to inspect formulas, summary KPIs, and dynamic charts.
4. **Final PDF Report**:
   - Open `Final_Business_Insights_Report.pdf` for executive takeaways and strategic business advice.
